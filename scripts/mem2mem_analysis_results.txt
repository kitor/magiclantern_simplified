1. Two functions perform dual-address (set_addr + set_addr2) DMA setup:

   a) 0xE080EA28 — Small helper (328 bytes), uses 3 EDMAC channels from
      a context struct. Sets source via set_addr, destination via set_addr2.
      Called from 0xE07D350E.

   b) 0xE083DE26 — Large function (842+ bytes), the MAIN mem-to-mem DMA
      setup. Uses 2 channel pairs. Has conditional logic: when the mem2mem
      flag is set (offsets +0x60/+0x68), calls set_addr2 for the destination
      address instead of set_addr for the source. Called via function pointer.

2. Function 0xE083D4BE uses set_addr2 alone (no set_addr), likely for
   a single-channel read-side address configuration.

3. The critical mem-to-mem setup pattern is:
     eld_edmac_set_addr(ch, src_phys_addr)    — program source (write side)
     eld_edmac_set_addr2(ch, dest_phys_addr)   — program destination (read side)
     eld_edmac_set_geom(ch, geometry)          — program transfer geometry
     
4. No eld_edmac_trigger calls in ShootVfx — the actual trigger happens
   elsewhere (likely via eld_edmac_config's CBR=1 mechanism or from
   a different code module).
